# Data handoff for collaborators

Status: current
Last updated: 2026-10-26
Version: 0.2
Scope: Four local GeoPackages for census, infrastructure, licensing and communities

These are the **local final files** discussed for the map and research work. The GeoPackages are **not stored on GitHub**; send the files separately. Each now has a [runnable notebook folder](../datasets/README.md) with a local `final.gpkg` copy. Paths below are relative to the project root except for the earlier census copy in `Documents/Data`.

| Dataset and local file | What it contains | How it was prepared; GitHub method |
| --- | --- | --- |
| **Census** — `datasets/census/final.gpkg` (an earlier external comparison copy was verified), layer `social` | 287,178 common comparison areas; English indicator names. `field_dictionary` maps each original field name to its English name; `overview` has municipality summaries. | 2010 and 2022 tracts were linked by largest **positive-area** overlap in both directions, grouped by connected matches, and the 2022 pieces were merged by `common_id`. Annual indicators retain their source denominators and missing-value rules. See [census and indicator methods](https://github.com/fab1s/brazil-project/blob/main/docs/methods.md) and [harmonisation policy](https://github.com/fab1s/brazil-project/blob/main/docs/harmonisation-policy.md). |
| **Obrasgov** — `datasets/obrasgov/final.gpkg`, layer `map_components` | 224,495 retained point/line components; `excluded_primary_state` records 2,346 components entirely outside their reported primary state. | Source project rows and coordinates were preserved. Geometries were split into components, screened for location concerns, and polygons omitted from the map. The approved rule then removed components entirely outside their reported primary state from this derivative. Eligibility is **not** verified geocoding. See [location policy](https://github.com/fab1s/brazil-project/blob/main/docs/obrasgov-location-policy.md) and [exclusion process](https://github.com/fab1s/brazil-project/blob/main/docs/obrasgov-primary-state-filter.md). |
| **IBAMA** — `datasets/ibama/final.gpkg`, layer `licensed_projects_st` | 8,494 preserved licensing records with point, line and polygon geometry and an English sector field. | The original processing joined geometry types and translated sector labels. This file is a preserved baseline; the active Python stage also writes separate intermediate results. See [infrastructure methods](https://github.com/fab1s/brazil-project/blob/main/docs/methods.md#infrastructure-and-land-value) and [IBAMA processing report](https://github.com/fab1s/brazil-project/blob/main/research/reports/ibama_data_extraction.md). |
| **IBGE favelas and communities** — `datasets/communities/final.gpkg`, layer `favelas_2022` | 12,348 preserved 2022 community polygons. | This is a preserved IBGE baseline; no new transformation of this file is documented in the active pipeline. The website's community asset was retained rather than rebuilt from this GeoPackage. See [map workflow](https://github.com/fab1s/brazil-project/blob/main/docs/web-map.md#inputs-and-preparation) and [baseline inventory](https://github.com/fab1s/brazil-project/blob/main/docs/evidence/baseline-files.csv). |

**Before using the files together:** the census GeoPackage is in EPSG:5880; the other three are in EPSG:4674. Reproject for a chosen spatial calculation without changing the supplied files. All 12,348 community IDs, but only 8,492 of 8,494 IBAMA source IDs, appear in the locally saved highest-zoom website tiles; the two missing IBAMA IDs are `136441` and `3347413`. Exact tile geometry and attributes remain unverified. The website is a display product, not the source for analytical geometry.
